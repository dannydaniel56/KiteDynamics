# KiteDynamics
Exploring kite structures through plane aerodynamics and physics. Code, models, and simulations

## 🎯 Goal
To model, simulate, and understand how kites behave like wings—bridging fun and science.

## 🧠 Topics Covered
- Lift and drag coefficients
- Angle of attack
- Structural design (bridle, sail, spars)
- Flight stability
- Wind interaction

## 📁 Project Structure
- `/models` – 3D kite/plane models
- `/simulations` – physics sims (Python/Matlab)
- `/docs` – research notes, references
- `/images` – diagrams, sketches

## 🛠️ Tools Used
- Python (NumPy, Matplotlib)
- Blender (3D modeling)
- OpenFOAM (CFD) – optional
